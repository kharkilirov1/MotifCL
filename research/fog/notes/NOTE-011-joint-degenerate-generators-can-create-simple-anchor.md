# NOTE-011 — Joint degenerate generators can synthesize a simple spectral anchor

Suppose a cyclic action T has order n, but the learned library exposes only
powers

\[
B=T^a,\qquad C=T^b.
\]

Each power may have a degenerate spectrum when `gcd(a,n)>1` or `gcd(b,n)>1`.
However the subgroup generated by B and C is generated by
`T^{gcd(a,b,n)}`.  If

\[
\gcd(a,b,n)=1,
\]

then integer combinations of a and b contain exponents coprime to n, hence the
joint grammar contains a primitive order-n action even if neither exposed
operator is primitive.

EXP-030 uses n=30, a=3 and b=10.  Both trained actions are spectrally
degenerate, but `BC=T^13` is primitive because `gcd(13,30)=1`.  The compiler
finds this composition without receiving a,b or n as semantic metadata.

Architectural consequence: a structural compiler should search the algebra
*generated by* the learned operators, not only score each operator in isolation.
A useful canonicalizing primitive may be latent in their composition closure.
